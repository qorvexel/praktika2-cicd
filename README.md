# Калькулятор

Учебный проект для практической работы № 2 по CI/CD.

Автор: Судец-Ребров Арсений.

## Возможности

- Сложение двух чисел.
- Умножение двух чисел.

## Запуск тестов

Из папки проекта выполнить:

python -m unittest discover -v

## Создание документации на компьютере

python -m pydoc -w calculator

После выполнения команды открыть calculator.html.

## Автоматическая проверка

GitHub Actions запускает тесты и создает документацию
после отправки изменений и при создании Pull Request.

HTML-документация доступна в разделе Artifacts
соответствующего запуска workflow.
